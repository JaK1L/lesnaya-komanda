# 🔧 Инструкция по применению миграций

## Проблема
После деплоя новых функций (профиль, админка через Discord роль) нужно применить миграции к базе данных, но у вас нет shell доступа на Render (бесплатный аккаунт).

## ⚠️ ВАЖНО: Сначала дождитесь деплоя!

Render еще деплоит новую версию API. Это занимает 2-5 минут.

**Проверить статус деплоя:**
```bash
python check-deploy.py
```

Этот скрипт будет проверять каждые 15 секунд, задеплоилась ли новая версия.

Когда увидите "✅ ДЕПЛОЙ ЗАВЕРШЕН!" - можно применять миграции.

---

## Решение
Я создал несколько способов применить миграции:

---

## ✅ СПОСОБ 1: Запустить bat-файл (САМЫЙ ПРОСТОЙ)

**⚠️ ВАЖНО: Сначала запустите `python check-deploy.py` и дождитесь "✅ ДЕПЛОЙ ЗАВЕРШЕН!"**

1. Дождитесь пока Render задеплоит изменения (запустите `python check-deploy.py`)
2. Откройте папку проекта в проводнике Windows
3. Найдите файл `apply-migrations.bat`
4. Дважды кликните по нему
5. Скрипт автоматически:
   - Проверит установлен ли Python
   - Установит нужные библиотеки (requests)
   - Применит обе миграции
   - Покажет результат

**Готово!** Миграции применены.

---

## ✅ СПОСОБ 2: Через pgAdmin (ПРЯМОЕ ПОДКЛЮЧЕНИЕ К БД)

**Используйте этот способ, если API не работает или деплой не завершается.**

1. Откройте pgAdmin
2. Подключитесь к вашей базе данных на Render:
   - Найдите External Database URL в Render Dashboard → Database
   - Формат: `postgresql://user:password@host:port/database`
   - Используйте эти данные для подключения в pgAdmin
3. Откройте Query Tool (правый клик на базе → Query Tool)
4. Откройте файл `migrations-direct.sql` из папки проекта
5. Скопируйте весь SQL код и вставьте в Query Tool
6. Нажмите Execute (F5)
7. Проверьте результат - должны появиться новые колонки

**Готово!** Миграции применены напрямую через SQL.

---

## ✅ СПОСОБ 3: Через PowerShell/CMD

**⚠️ Требует завершения деплоя на Render**

1. Откройте PowerShell или CMD в папке проекта
2. Выполните команду:
```bash
python apply-migrations.py
```

Скрипт применит обе миграции и покажет результат.

## ❓ Что делают миграции?

### Миграция 1: add_profile_fields
Добавляет колонки в таблицу users:
- `site_nickname` - никнейм на сайте
- `bio` - описание профиля
- `is_hidden` - скрыть себя с сайта

### Миграция 2: add_is_admin_column
Добавляет колонку в таблицу users:
- `is_admin` - флаг админа (автоматически ставится для пользователей с ролью 🐓ПИТУХ🐓)

---

## 🚨 Важно

- Миграции нужно применить **ОДИН РАЗ** к базе данных
- Это влияет на **ВСЕХ пользователей**, не только на вас
- После применения миграций все функции профиля и админки заработают
- Если миграции уже применены, повторное применение не навредит (используется `IF NOT EXISTS`)
