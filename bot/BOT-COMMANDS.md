# 🤖 Команды Discord бота Лесной Команды

## 📊 Статистика

### `!лес`
Показывает информацию о сервере
- Количество участников
- Онлайн пользователей
- ID сервера

**Пример:**
```
!лес
```

### `!профиль [@пользователь]`
Показывает профиль игрока
- Дата присоединения
- Количество сообщений
- Время в голосовых каналах
- Роли

**Примеры:**
```
!профиль
!профиль @JaK1L
```

### `!топ [число]`
Топ игроков по активности (сообщениям)
- По умолчанию показывает топ-10
- Можно указать другое число (1-50)

**Примеры:**
```
!топ
!топ 20
```

## 🌐 Сайт

### `!сайт`

**Пример:**

**Пример:**

### `!новости [число]`
Последние новости с сайта
- По умолчанию показывает 3 новости
- Можно указать другое число

**Примеры:**
```

```

Ближайшие события и турниры
- По умолчанию показывает 3 события
- Дата и время события
- Статус (регистрация, планируется и т.д.)

**Примеры:**
```
!события
!события 5
```

### `!стримы`
Ссылка на страницу стримов
- Список стримеров команды
- Live статус
- Расписание

**Пример:**
```

```

### `!соцсети`
Ссылки на все соцсети команды
- Discord

**Пример:**

## 🔧 Для администраторов

### Автоматическая синхронизация

Бот автоматически:
- ✅ Синхронизирует участников сервера с базой данных
- ✅ Обновляет статусы и активности (presence)
- ✅ Отслеживает сообщения в каналах
- ✅ Логирует время в голосовых каналах
- ✅ Обновляет аватары и никнеймы

### События

Бот реагирует на:
- `on_ready` - запуск бота, синхронизация
- `on_message` - логирование сообщений
- `on_voice_state_update` - логирование войса
- `on_presence_update` - обновление статусов

## 🚀 Установка и запуск

### Локально

```bash
cd bot
pip install -r requirements.txt
python main.py
```

### На Railway

1. Создать новый проект
2. Подключить GitHub репозиторий
3. Указать папку `bot` как root directory
4. Добавить переменные окружения:
   - `DISCORD_BOT_TOKEN`
   - `DISCORD_GUILD_ID`
   - `DATABASE_URL`
   - `API_URL` (опционально)
   - `WEBSITE_URL` (опционально)

---

```env
# Обязательные
```

## 📚 Технические детали

### Используемые библиотеки
- `discord.py` - Discord API
- `asyncpg` - PostgreSQL async driver
- `aiohttp` - HTTP клиент для API
- `python-dotenv` - Переменные окружения

### База данных

Бот работает с таблицами:
- `users` - пользователи Discord
- `discord_presence` - статусы и активности
- `activity_log` - логи сообщений
- `voice_sessions` - сессии в войсе

### Cogs (модули)

- `cogs/website.py` - команды для взаимодействия с сайтом
