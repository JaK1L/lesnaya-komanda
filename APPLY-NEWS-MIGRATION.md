# Применение миграции для добавления image_url в таблицу news

## Что сделано

1. ✅ Создана миграция `backend/migrations/add_image_url_to_news.sql`
2. ✅ Обновлены backend схемы (schemas.py)
3. ✅ Обновлены API endpoints (admin.py, content.py)
4. ✅ Обновлена админка для добавления URL картинки
5. ✅ Созданы компоненты NewsCard и NewsModal
6. ✅ Добавлена секция новостей на главную страницу

## Что нужно сделать

### 1. Применить миграцию в Neon

Зайди в Neon Console (https://console.neon.tech/) и выполни SQL:

```sql
-- Добавление поля image_url в таблицу news
ALTER TABLE news ADD COLUMN IF NOT EXISTS image_url TEXT;

-- Комментарий
COMMENT ON COLUMN news.image_url IS 'URL изображения для новости';
```

### 2. Закоммитить и запушить изменения

```bash
git add .
git commit -m "feat: добавлена секция новостей с картинками и модальным окном"
git push
```

### 3. Проверить деплой

- Backend на Render автоматически задеплоится
- Frontend на Vercel автоматически задеплоится

### 4. Протестировать

1. Зайди в админку: https://lesnaya-komanda.vercel.app/admin
2. Создай новость с картинкой (добавь URL изображения)
3. Опубликуй новость
4. Проверь главную страницу - должна появиться секция "Новости"
5. Кликни на новость - должно открыться модальное окно
