# CS2 API - Текущий статус

## Проблема

Tracker.gg API ключ `057f6380-58d8-4ed7-afcb-8a54c510c7c1` не работает:
- Возвращает **401 Unauthorized**
- Ключ распознается, но не проходит авторизацию
- Возможно требует активации или дополнительной настройки

## Решение

Реализована двухуровневая система получения статистики CS2:

### 1. Основной источник: Tracker.gg API
- Если ключ валиден → получаем полную статистику
- Если 401/404 → переходим к Steam API

### 2. Fallback: Steam API
- Используем Steam Web API ключ: `2B3F8147466380EE76E0985131D2632C`
- Endpoint: `ISteamUserStats/GetUserStatsForGame/v2/`
- AppID: 730 (CS:GO/CS2)

## Ограничения Steam API

Steam API для CS2 статистики работает только если:
1. ✅ Профиль Steam публичный
2. ✅ Игровая статистика открыта
3. ✅ У игрока есть CS2 и сыгранные матчи

Если профиль приватный → возвращается **400 Bad Request** или **403 Forbidden**

## Что показывается пользователю

### Если Tracker.gg работает:
- Kills, Deaths, K/D
- Wins, Matches Played
- MVPs, Headshots, Headshot %
- Win Rate, Damage per Round

### Если только Steam API:
- Kills, Deaths, K/D
- Wins, Matches Played
- MVPs, Headshots, Headshot %
- Win Rate

### Если ничего не работает:
- Показывается сообщение "Статистика недоступна"
- Возможные причины:
  - Профиль приватный
  - Игровая статистика скрыта
  - Нет сыгранных матчей CS2
