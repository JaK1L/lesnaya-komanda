# 📚 Документация проекта

Эта папка содержит всю техническую документацию, отчеты и инструкции по проекту.

## 📁 Структура

Все .md файлы автоматически создаются в этой папке для удобства навигации.

## 🔍 Основные документы

Документация создается автоматически в процессе разработки и содержит:
- Отчеты о выполненных задачах
- Инструкции по деплою
- Технические спецификации
- Руководства по миграциям

## ⚠️ Важно

Файлы в этой папке НЕ коммитятся в Git (см. `.gitignore`), кроме этого README.
