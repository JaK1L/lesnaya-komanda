# Функционал "Наша команда"

## Описание

Страница с досье на каждого участника Лесной Команды. Администраторы могут управлять составом команды и редактировать информацию о каждом участнике.

## Структура

### База данных

Добавлены новые поля в таблицу `users`:
- `real_name` - реальное имя (опционально)
- `bio` - биография/описание
- `telegram_url` - ссылка на Telegram
- `tiktok_url` - ссылка на TikTok
- `youtube_url` - ссылка на YouTube
- `is_team_member` - флаг члена команды
- `team_role` - роль в команде (Стример, Модератор и т.д.)
- `team_order` - порядок отображения

### Backend

**Публичный API:**
- `GET /api/team` - список членов команды для публичной страницы

**Admin API:**
- `GET /api/admin/team` - список команды для админки
- `PUT /api/admin/team/{discord_id}` - обновить информацию о члене команды
- `DELETE /api/admin/team/{discord_id}` - убрать из команды
- `GET /api/admin/users/search?q=` - поиск пользователей для добавления

### Frontend

**Публичная страница:**
- `/team` - страница "Наша команда"
- Карточки с аватаром, именем, ролью, биографией
- Ссылки на соцсети (Twitch, Telegram, TikTok, YouTube)
- Адаптивный дизайн

**Админ-панель:**
- `/admin/team` - управление командой
- Поиск пользователей для добавления
- Редактирование информации о каждом участнике
- Изменение порядка отображения
- Удаление из команды

## Использование

### Применение миграции

```bash
cd backend
python apply_team_members_migration.py
```

### Добавление участника в команду

1. Зайти в админ-панель `/admin`
2. Перейти в "👥 Наша команда"
3. Найти пользователя через поиск
4. Нажать "Добавить"
5. Заполнить информацию (имя, роль, биография, соцсети)
6. Сохранить

### Редактирование участника

1. В списке команды нажать "Редактировать"
2. Изменить нужные поля
3. Нажать "Сохранить"

### Порядок отображения

Участники сортируются по полю `team_order` (по возрастанию). Чем меньше число, тем выше в списке.

Страница выполнена в едином стиле с остальным сайтом:
- Темный фон #1e1e1e
- Шрифт Manrope
- Фиолетовые акценты
- Карточки с hover эффектами
- Адаптивная сетка

## Поля участника

- **Discord Username** - никнейм в Discord (обязательно)
- **Реальное имя** - настоящее имя (опционально)
- **Роль в команде** - Стример, Модератор и т.д. (опционально)
- **Биография** - описание участника (опционально)
- **Twitch** - автоматически из профиля стримера
- **Telegram** - ссылка на Telegram (опционально)
- **TikTok** - ссылка на TikTok (опционально)
- **YouTube** - ссылка на YouTube (опционально)
- **Порядок** - число для сортировки (по умолчанию 0)

## Примечания

- Twitch username берется из существующего поля `twitch_username` в таблице users
- Если указано реальное имя, оно отображается вместо Discord username
- Пустые соцсети не отображаются на карточке
- Администраторы могут добавлять только существующих пользователей из БД
