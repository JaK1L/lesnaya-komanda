# Обновление страницы /streams с Twitch API

## Что сделано

Полностью переделана страница `/streams` с интеграцией Twitch API для отображения актуальной информации о стримерах.

## Новые возможности

### 1. Получение количества фолловеров

Обновлен `TwitchService.get_user_info()` для получения количества фолловеров:

```python
# Получаем количество фолловеров
followers_url = 'https://api.twitch.tv/helix/channels/followers'
followers_params = {'broadcaster_id': user_id}
followers_count = followers_data.get('total', 0)
```

### 2. Обновленный API эндпоинт

`GET /api/streamers` теперь возвращает:

```json
{
  "id": 1,
  "twitch_username": "jak1lqa",
  "display_name": "JaK1Lqa",
  "avatar_url": "https://...",
  "description": "Описание канала",
  "stream_url": "https://twitch.tv/jak1lqa",
  "followers_count": 1234,
  "is_live": true,
  "game_name": "Counter-Strike 2",
  "stream_title": "Играем в CS2!",
  "viewer_count": 150,
  "thumbnail_url": "https://..."
}
```

### 3. Новый дизайн карточек стримеров

**Если стример онлайн:**
- Превью стрима (thumbnail)
- Индикатор 🔴 LIVE
- Название стрима
- Текущая игра
- Количество зрителей
- Количество фолловеров

**Если стример оффлайн:**
- Аватар стримера
- Описание канала
- Количество фолловеров

### 4. Разделение на секции

- **Сейчас в эфире** - стримеры которые онлайн
- **Все стримеры** - оффлайн стримеры

### 5. Улучшенная обработка ошибок

- Спиннер загрузки
- Сообщение об ошибке с кнопкой повтора
- Graceful fallback если Twitch API недоступен

## Структура компонентов

### StreamerCardNew

Новый компонент карточки стримера встроен прямо в страницу:

```tsx

```

Отображает:
- Превью стрима или аватар
- Имя и username
- Twitch иконку
- Название стрима / описание
- Игру
- Статистику (зрители + фолловеры)

## Использование

### Добавление стримера

1. Откройте админку → Стримеры
2. Добавьте ссылку на Twitch канал
3. Стример автоматически появится на `/streams`

### Что показывается автоматически

- ✅ Аватар из Twitch
- ✅ Имя и username
- ✅ Описание канала
- ✅ Количество фолловеров
- ✅ Live статус
- ✅ Превью стрима (если онлайн)
- ✅ Название стрима (если онлайн)
- ✅ Игра (если онлайн)
- ✅ Количество зрителей (если онлайн)

## Troubleshooting

### Не показываются фолловеры

Проверьте что Twitch API ключи правильные и имеют доступ к `channel:read:followers`.

### Не показывается превью стрима

Убедитесь что стример действительно онлайн и Twitch API возвращает `thumbnail_url`.

### Ошибка загрузки

1. Проверьте что бэкенд запущен
2. Проверьте что таблица `streamers` существует
3. Проверьте логи бэкенда на ошибки Twitch API
