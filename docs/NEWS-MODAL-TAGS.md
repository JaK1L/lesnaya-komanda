## Что сделано

### 1. База данных
- Добавлено поле `tags` (TEXT[]) в таблицу `news`
- Миграция: `backend/add_news_tags.py`

### 2. Backend (FastAPI)

**Обновлены модели:**
- `NewsCreate` - добавлено поле `tags: List[str]`
- `NewsOut` - добавлено поле `tags: List[str]`
- `NewsPublic` - добавлено поле `tags: List[str]`

**Обновлены роуты:**
- `GET /api/admin/news` - возвращает теги
- `POST /api/admin/news` - принимает теги

**Валидация тегов:**
- Максимум 10 тегов на новость

## Использование

### Создание новости:
1. Нажать "+ Добавить" в админке
2. Заполнить заголовок и содержание
3. Добавить изображение (опционально)
4. Добавить теги через input + Enter или кнопку
5. Выбрать статус публикации
6. Нажать "Создать новость"

### Редактирование:
1. Нажать ✏️ на карточке новости
2. Изменить данные
3. Нажать "Сохранить изменения"

### Теги:
- Вводите тег и нажимайте Enter или "+ Добавить"
- Удаляйте теги кнопкой ✕
- Теги отображаются зеленым цветом
- Максимум 10 тегов, 30 символов каждый

## API примеры

### Создание новости с тегами:
```json
POST /api/admin/news
{
  "title": "Новое обновление",
  "content": "Описание обновления...",
  "image_url": "https://example.com/image.jpg",
  "published": true,
  "tags": ["обновление", "патч", "новости"]
}
```

### Ответ:
```json
{
  "id": 1,
  "title": "Новое обновление",
  "content": "Описание обновления...",
  "image_url": "https://example.com/image.jpg",
  "published": true,
  "tags": ["обновление", "патч", "новости"],
  "author_id": 1,
  "created_at": "2025-01-15T10:00:00",
  "updated_at": null
}
```

- Преобразование `None` в `[]`

**React:**
