# Git Workflow с Kiro: Правила коммитов и веток

## 1. Перед началом работы над фичей
Всегда уточни, в какой ветке мы находимся.
- Если мы в `main/master` — попроси создать новую ветку.
- **Команда:** `git checkout -b feature/[название-фичи]`

## 2. Процесс коммита (Атомарность)
Один коммит = одна логическая единица работы.
- **Плохо:** `фикс багов и добавление кнопки`
- **Хорошо:** `исправлена ошибка undefined в профиле`
- **Хорошо:** `добавлена кнопка входа через Google`

**Структура сообщения коммита:**
<тип>(<область>): <описание>
