**Статус:** ✅ ИСПРАВЛЕНО

2. Массив `participants` требовал преобразования

4. Валидация Telegram URL не поддерживала посты `/123`

**Коммиты:**
- `ce1c0cb` - fix(backend): убрать channel_binding из DATABASE_URL
- `212ea0f` - fix(admin): обработка массива participants
- `7b47d97` - fix(admin): event_date может быть NULL
- `30b2937` - fix(validation): поддержка постов в Telegram URL
