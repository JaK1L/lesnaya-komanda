# Настройка загрузки изображений

## Что сделано

Добавлена возможность загружать изображения с компьютера/телефона в админке новостей.

## Как получить API ключ ImgBB (бесплатно)

1. Зайди на https://api.imgbb.com/
2. Нажми "Get API Key"
3. Зарегистрируйся или войди через Google/Facebook
4. Скопируй свой API ключ

## Настройка

1. Открой файл `frontend/lib/imageUpload.ts`
2. Найди строку:
```typescript
const IMGBB_API_KEY = '8d32e7f8c8e9c8f8c8e9c8f8c8e9c8f8'
```
3. Замени на свой ключ:
```typescript
const IMGBB_API_KEY = 'твой_ключ_здесь'
```

## Как использовать

1. Зайди в админку → Новости
2. Нажми "Добавить" или редактируй существующую новость
3. В поле "Изображение" можешь:
   - Нажать "📁 Выбрать файл" и загрузить с компьютера/телефона
   - Или вставить URL изображения вручную
4. После загрузки появится превью
5. Можно удалить изображение кнопкой "✕ Удалить"

## Ограничения ImgBB (бесплатный план)

- Максимальный размер файла: 32 MB
- Неограниченное количество загрузок
- Изображения хранятся бессрочно
- Поддерживаемые форматы: JPG, PNG, GIF, BMP, WEBP

## Альтернативы

Если ImgBB не подходит, можно использовать:

### 1. Cloudinary (бесплатно до 25GB)
```typescript
// Установить: npm install cloudinary
const cloudinary = require('cloudinary').v2
```

### 2. Uploadcare (бесплатно до 3000 файлов/месяц)
```typescript
// Установить: npm install @uploadcare/upload-client
```

### 3. Свой backend
Можно добавить endpoint на backend для сохранения файлов на сервере или в S3.
