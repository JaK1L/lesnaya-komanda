## 📋 Что было сделано

### 🤖 Новые команды бота

#### Команды для взаимодействия с сайтом:

1. **`!сайт`** - Ссылка на официальный сайт
   - Красивый embed с описанием
   - Список возможностей сайта

2. **`!мойпрофиль`** - Персональная ссылка на профиль
   - Прямая ссылка на профиль пользователя
   - Инструкция по редактированию

3. **`!новости [число]`** - Последние новости с сайта
   - Получает данные через API
   - По умолчанию показывает 3 новости
   - Можно указать другое количество

4. **`!события [число]`** - Ближайшие события
   - Получает данные через API
   - Показывает дату, время, статус
   - Эмодзи для разных игр (CS2, Dota 2, Valorant)

5. **`!стримы`** - Ссылка на страницу стримов
   - Информация о платформах (Twitch, YouTube)
   - Прямая ссылка на страницу

6. **`!соцсети`** - Все соцсети команды
   - Discord, Telegram, YouTube
   - Ссылки на каналы

7. **`!помощь`** - Список всех команд
   - Полный список команд с описанием
   - Разделение по категориям

## 🚀 Использование

### Примеры команд

```
!помощь              # Список всех команд
!сайт                # Ссылка на сайт
!мойпрофиль          # Твой профиль
!новости             # Последние 3 новости
!новости 5           # Последние 5 новостей
!события             # Ближайшие 3 события
!стримы              # Страница стримов
!соцсети             # Все соцсети
!профиль @user       # Профиль пользователя
!топ                 # Топ по активности
!лес                 # Инфо о сервере
```

### Для пользователей

1. Открой Discord
2. Напиши `!помощь` чтобы увидеть все команды
3. Используй команды для взаимодействия с сайтом

### Для администраторов

Бот автоматически:
- Синхронизирует данные при запуске
- Обновляет presence при изменениях
- Логирует активность пользователей


### API интеграция

Бот использует API эндпоинты:
- `GET /api/news` - получение новостей
- `GET /api/events` - получение событий

### Переменные окружения

```env
# Обязательные

# Опциональные (для команд сайта)
API_URL=https://api.lesnaya-komanda.com
```

## 🔄 Обновление бота на Railway

### Автоматическое обновление
1. Изменения уже запушены в GitHub
2. Railway автоматически задеплоит обновления
3. Бот перезапустится с новыми командами

### Ручное обновление
```bash
# На Railway
railway up

# Или через GitHub
git push origin main
# Railway автоматически задеплоит
```

### Проверка
```
# В Discord
!помощь
# Должны появиться новые команды
```
