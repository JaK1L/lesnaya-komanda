🔧 MIGRATION TOOL

Инструкция:

  1. Войдите на сайт через Discord (нужна роль 🐓ПИТУХ🐓 или старый админ логин)
  2. Скопируйте токен из localStorage (откройте DevTools → Console → введите: localStorage.getItem('lesnaya_token') или localStorage.getItem('lesnaya_admin_token'))
  3. Вставьте токен в поле ниже
  4. Нажмите "Проверить статус" чтобы узнать, нужна ли миграция
  5. Если нужна миграция, нажмите "Применить миграцию"
